## 3. 无线与 USB

### 3.1 BLE 角色支持（**关键差异：CH572 只能做从机**）

| 型号 | 从机 Peripheral | 主机 Central | 广播 Broadcaster | 扫描 Observer | 同时主从 | 多连接 |
|---|---|---|---|---|---|---|
| **CH572D / Q / R** | ✔ | **✘** | ✔ | ✔ | **✘** | 1 从机 |
| CH592X / F / A / D | ✔ | ✔ | ✔ | ✔ | ✔ | 最多 1 从 + 3 主 |
| CH591F / D / R | ✔ | ✔ | ✔ | ✔ | ✔ | 最多 1 从 + 3 主 |
| CH585M / F / C / D | ✔ | ✔ | ✔ | ✔ | ✔ | 最多 1 从 + 3 主 |
| CH584M / X / F | ✔ | ✔ | ✔ | ✔ | ✔ | 最多 1 从 + 3 主 |
| CH32V003 / X035 / L103 / V203 | — | — | — | — | — | 无 BLE |

> **CH572 的 BLE 库仅提供从机（Peripheral）角色**：`libCH572BLE_PERI.a` 中只定义了
> `GAP_PROFILE_PERIPHERAL`，且**不包含** `GAPRole_CentralInit`、`GAP_DeviceDiscoveryRequest`、
> `GAP_EstablishLinkReq` 等主机 API。因此 CH572 **无法主动扫描并连接其他 BLE 设备**。
>
> CH59x / CH58x 的库定义了全部 4 种角色（`GAP_PROFILE_BROADCASTER/OBSERVER/PERIPHERAL/CENTRAL`），
> 支持**同时主从**（一边被手机连接、一边连接传感器），连接数由 `bleConfig_t.ConnectNumber` 配置：
> 低 2 位为从机数、高位为主机数（本项目 `ble_config.h` 默认 `1 从 + 3 主`）。

**典型场景对照**

| 场景 | CH572 | CH592 / CH585 |
|---|---|---|
| 手环/传感器（被手机连接） | ✔ | ✔ |
| 蓝牙遥控器（只广播） | ✔ | ✔ |
| 蓝牙网关（连多个传感器） | **✘** | ✔ |
| 主从一体（被手机连 + 连外设） | **✘** | ✔ |
| BLE 抓包/嗅探 | ✘ | ✔（Observer） |

> 需要「扫描周边 BLE 设备」或「主动连接外设」时，**必须选 CH592 / CH591 / CH585 / CH584**。

## 12. 型号命名规则

### 12.1 CH5xx 系列

```
CH  5 9 2  X
│   │ │ │  └─ 封装/引脚数标识
│   │ │ └──── 系列内型号（X/F/A/D/R/Q）
│   │ └────── 子系列（1=精简版，2=标准版）
│   └──────── 系列（57=CH57x，58=CH58x，59=CH59x）
└──────────── 厂商前缀
```

| 后缀 | 含义 | 常见封装 |
|---|---|---|
| X | 最大引脚数版本 | QFN32 |
| F | 中等引脚（Full） | QFN28 / QFN32 |
| A | F 的低压变体（2.3 V） | QFN28 |
| D | 少引脚版本 | QFN20 |
| R | 极简封装 | TSSOP16 |
| M | 最多引脚（Max） | QFN48 |
| C | 紧凑型 | QFN26C3 |
| Q | 最小封装 | DFN10X3 |

> CH58x 的 `CH584X` 是特例：X 表示**大 Flash 版本**（480 KB CodeFlash + 512 KB DataFlash），
> 而非最大引脚数（引脚数与 CH584M 相同，均为 QFN48 / 40 GPIO）。

### 12.2 CH32 系列

```
CH 32 V 2 03 R B T 6
│  │  │ │ │  │ │ │ └─ 温度等级（6 = -40~85℃）
│  │  │ │ │  │ │ └─── 封装（T = LQFP，P = TSSOP，U = QFN，M = SOP，R = QSOP）
│  │  │ │ │  │ └───── Flash 容量（B = 128K，8 = 64K，6 = 32K）
│  │  │ │ │  └─────── 引脚数（R = 64，C = 48，K = 32，G = 28，F = 20）
│  │  │ │ └────────── 子系列编号
│  │  │ └──────────── 内核/系列（V = 通用，X = 互联，L = 低功耗）
│  │  └────────────── 32 位
│  └───────────────── 厂商前缀
```

| 字段 | 取值 | 含义 |
|---|---|---|
| 引脚数 | R / C / K / G / F / D / J / A | 64 / 48 / 32 / 28 / 20 / 12 / 8 / 16 |
| Flash | B / 8 / 7 / 6 / 4 | 128K / 64K / 62K / 32K / 16K |
| 封装 | T / P / U / M / R | LQFP / TSSOP / QFN / SOP / QSOP |
